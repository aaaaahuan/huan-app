# A4 原页容器 Review

## 本次实现

- 点击收藏才加载原页，使用独立 WebContentsView，不使用 iframe/oEmbed。
- 单一网页区域；切换收藏销毁旧页，重新打开收藏原始 URL，不保留各收藏的浏览历史。
- 支持前进、后退、刷新、停止；地址只读。原页跳转与左侧选中项独立。
- 普通新窗口网页链接转到当前容器；POST 弹窗、下载及非网页协议拦截并提示。
- 网络失败、30 秒超时、页面进程停止提供失败提示与重试；HTTP 错误响应仍展示原站页面。
- 设置打开前隐藏原生视图，关闭后恢复；折叠侧栏、调整窗口时重新定位。
- 每个平台独立内存会话，无远程 preload，沙箱与上下文隔离开启；权限请求默认拒绝。

## 验收步骤（待用户执行）

1. `nvm use` 后运行 `pnpm dev`；打开已配置的收藏，核对显示的是原站而非摘要。
2. 在帖子内点击普通链接，确认仍在中间展示，地址变化但左侧收藏不变；核对前进后退和刷新。
3. 从 A 切到 B 再切回 A，确认回到 A 的原始 URL，旧页面不继续播放声音。
4. 加载时停止、重新刷新；断网后刷新应提示失败或在 30 秒后超时，恢复网络后可重试。
5. 阅读时打开设置，确认页面不遮挡设置；取消后恢复原页而非重新加载。核对折叠侧栏和窗口缩放后的网页边界。
6. 快速连续切换收藏，确认地址和内容不会被旧收藏迟到事件覆盖；搜索/筛选不改变当前阅读选择。
7. 关闭主窗口再打开，应保留阅读状态；Cmd+Q 后重新启动，不自动选中帖子，也不承诺保存登录态。
8. 分别核对 X、Reddit、YouTube 的实际加载和站内交互；反爬、登录验证、DRM 等平台限制需实机确认，不因构建通过判定兼容。
