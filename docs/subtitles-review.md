## 实现边界

主进程管理服务 IO、safeStorage 凭据、最多 20 视频的缓存及提交未知记录；IPC 严格校验可信发送方、videoId、当前视频和参数。HTTP 固定 origin、拒绝重定向、单次 20s、获取等待 120s、响应 4MiB；正文 2MiB/30,000 段，同凭据串行并保守间隔 12s，429 服从 Retry-After。只接受匹配视频、非空、单调有限起点、source 为 caption 或 extension_upload 的完整结果；保留真实来源，不接受 ASR、翻译或未知来源。

播放器只观察实际 HTTPS YouTube watch 页面和对应主播放器；固定隔离世界脚本、generation 和新鲜度检查防止旧视频位置串页，watchdog 触发全文手动降级。停止未提交的导航后重新绑定实际页面。seek 再核对当前页面、广告、duration 和 seekable，不改播放状态。

阅读 UI 与 AIChat 保持挂载，字幕入口按实际 URL 显示；A/B 加载间隙不重置已选字幕 Tab。展开量单调保留，广告停止推进，手动滚动/选文优先；选区复制仅输出字幕原文。AI 发送同步克隆已有全文和新鲜位置，字幕材料授权版本 3，保留既有文章授权；工具分段读取并展示真实来源，Run 结束释放本轮缓存。
