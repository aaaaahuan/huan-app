## 实现范围

- 标题栏设置入口，沿用浅绿色视觉；原生文件选择器，支持手填绝对路径。
- X、Reddit、YouTube 独立设置启用状态和 Markdown 路径；首次均停用，未选择文件时不虚构路径。
- 主进程校验 IPC 来源、配置结构、绝对路径及扩展名；启用来源额外校验普通文件和读取权限。停用来源允许保留暂时不可访问的合法路径。
- 设置版本为 1，保存位置固定 `~/.huan-app/settings.json`。不读取收藏正文、不写入 Obsidian，不新增依赖或自动测试技术。
- 临时文件使用 0600 权限，完整写入并 sync 后 rename。应用内串行保存，基于读取版本摘要检测已发生的外部修改，避免直接覆盖；不承诺与任意外部编辑器之间的跨进程事务锁。
- 非法/未知版本配置只报错，不自动覆盖；保存失败保留输入，磁盘写入失败保留旧文件。缺失配置返回默认值，首次打开设置不自动创建文件。
- 取消、关闭按钮、Escape 遇到未保存修改时确认放弃；macOS 关闭窗口保留草稿，完全退出触发原生确认。

## 人工验收

1. 打开右上角「设置」，确认三个平台及文件选择入口可用，焦点不会落到面板外。
2. 为一个平台选择实际 Markdown 文件并启用；保存，确认成功提示。
3. Cmd+Q 退出后重启，再打开设置，确认路径和启用状态恢复。
4. 修改路径后取消/关闭/Escape，选择继续编辑应保留输入，选择放弃应恢复上次保存内容。
5. 启用空路径或填写不存在的 `.md` 路径，保存应失败并标记平台，原配置不变。
6. 在文件选择器取消，不应清除已填写路径；处理期间不能重复保存或关闭设置。
7. 全部停用后可保存；重新启用时再次检查来源文件。
8. 编辑后直接 Cmd+Q，确认可以继续编辑或明确放弃退出；关闭窗口再从 Dock 恢复应保留草稿。
