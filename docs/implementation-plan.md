# huan-app 实施约定

## 已确认规则

本次用户确认的变更优先于旧 v2.2 文档中的 SQLite、平台同步和时间排序设计。旧 Obsidian 方案尚未整体重写，不按冲突条款继续实施。

- 工程/产品名 huan-app，应用标识 com.huan.app，本地目录 `~/.huan-app/`。
- Obsidian Markdown 为收藏权威来源；app 只读，不回写、不采集平台收藏。
- 成功读取后以原文为准，源端删除的行从列表移除；失败不当作空列表。
- 完全保持源文件行顺序，不按日期、标题、首次读取时间排序。
- 一个平台映射一个文件。跨文件没有天然总顺序，默认按设置中的来源顺序拼接，文件内顺序不变；搜索/筛选保持相对顺序。
- 以平台 + URL 去重，重复保留第一次出现位置，不擅自移除参数或按帖子 ID 合并。
- 正常启动读取一次，隐藏窗口重开不重读；来源配置保存后重读受影响来源。不定时刷新、不监听文件。

## 表格和副本（A2 实现）

沿用已有笔记，不改动正文或表格：

| 采集日期 | 标题 / 列表文字 | 来源 | 帖子链接 |
| --- | --- | --- | --- |
| 2026-09-21 | 示例 | 书签 | <https://x.com/example/status/123> |

支持普通 URL、尖括号 URL、Markdown 链接，只接受 HTTP/HTTPS。标题可空，展示回退 URL；兼容 `&#124;` 和 `<br>`，不执行 HTML。日期不用于排序。

合法表头且无数据行是有效空列表；缺文件、不可读、无合法表格、非法行是失败，保留该来源有效副本并提示文件/行号，其他来源不受影响。

`~/.huan-app/bookmarks/last-success.json` 存格式版本、来源标识/路径、各来源成功读取时间及有序条目；这是解析结果副本，不是原始 Markdown 或完整历史备份，不含 Cookie、聊天、页面正文。

解析校验成功后临时写入并原子替换，写入失败保留旧副本。路径变更时旧副本不能冒充新路径读取成功；原文与副本均无效则展示设置引导，不谎报空收藏读取成功。

## 模块与实施步骤

基础设施在 `main/app`；按功能逐步增加 `main/settings`、`main/bookmarks`、`main/browser`，UI 对应 `renderer/src/features`。跨进程接口在 `shared/contracts/<feature>.ts`；不让 React 直接访问 Node，不给远程页面应用 preload。

AI 后续增加 `main/ai`、`workers/ai`、`features/ai-chat`。AI 接收收藏会话标识、显式页面材料与问题，不直接读取 Obsidian，不跟随导航替换上下文。没有实际需求前不建空目录、插件框架、monorepo 或公共服务层。

每步交付代码、静态检查和人工演示后停下来 Review。按用户要求，当前不引入单元测试、E2E 或其他自动化测试技术。工作量是相对复杂度，不是工期。

| 步骤 | 内容 | 验收重点 | 工作量 |
| --- | --- | --- | --- |
| A0 | 名称、目录、移除 SQLite 与空服务 | 启动、受限 IPC、独立打包 | 中 |
| A1 | 设置模块与配置存储 | 路径/来源、校验、保存/取消、重启恢复 | 中 |
| A2 | 收藏读取和有效副本 | 原文顺序、去重、源删除、空表与失败区分 | 中 |
| A3 | 收藏列表 | 搜索、筛选、折叠、选择、空状态 | 中 |
| A4 | 原页容器 | 平台真实页面、切换、前进后退、异常 | 大 |
| A5 | 登录态配置与管理 | 原站登录、持久/本次会话、清除、平台隔离 | 大 |
| A6 | 基础版验收与交付 | 不依赖 AI 的阅读流程，签名公证另行验证 | 中 |
| B0 | AI 接口 | 与存储和页面内部实现解耦 | 小 |
| B1 | 正文读取 | 不读评论，登录页/读取失败/导航竞态 | 中 |
| B2 | Harness 与配置 | 默认后端、检测、真实只读权限 | 大 |
| B3 | 对话会话 | 流式、停止、收藏 × Harness 隔离，无 steer | 大 |
| B4 | 上下文 | 首次注入、主动附加一页、授权，不自动换上下文 | 中 |
| B5 | AI 验收 | 失败不影响阅读，清空/退出/迟到回复 | 中 |

设置分收藏来源、登录与隐私、阅读布局、AI；A1 建设置基础，登录行为在 A5 接入，Harness 在 B2 接入，不做无效开关。

A5 已实现分平台内存/持久会话与独立清除。保存策略在完全退出重启后生效，现有会话不迁移，切回内存不会隐式清除旧持久数据；清除按钮同时清除两类分区并保留收藏。A6 按 `docs/a5-a6-review.md` 记录实机证据及未通过/待用户验证项，不以构建成功替代真实登录验收。

A0 启动问题必须解决后才能判定基础运行验收通过，构建不等于运行。
