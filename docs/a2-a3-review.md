# A2 + A3 Review

## 范围

读取设置指定的 Markdown，解析约定四列表格，管理最近成功副本；左侧列表支持搜索、平台筛选、分页、折叠与选择，中间显示选中条目的信息。没有 A4 原始网页，也不运行 AI。本轮不新增依赖、自动化测试框架或测试文件，不自动提交。

## 数据规则

- 每次进程启动仅读取一次；React 查询与隐藏窗口恢复不会触发文件重读。
- 设置保存后只重读启用状态或路径变化的来源。原文编辑后需要退出重启；不提供实时监听、手动平台同步或自动采集。
- 文件内保持原文顺序；跨平台按 X、Reddit、YouTube 拼接。平台 + 解包后的 URL 去重，保留第一次位置与内容，不移除查询参数或转换域名。
- 支持普通 URL、尖括号 URL、Markdown 链接、转义管道符、`&#124;`、`<br>` 和常见实体；表格外正文与围栏代码块忽略。不执行 Markdown/HTML，不使用 dangerouslySetInnerHTML。
- 合法表头和分隔行但无记录是有效空表；找不到表格、非法 URL、错误列数等失败不覆盖副本。错误含原文件行号，路径可在来源状态查看。
- 单个来源限制 8 MB，读取超时 10 秒，拒绝非 UTF-8 或读取期间变化的文件。副本限制 64 MB，校验版本/字段/条目身份。
- 最近成功副本 `~/.huan-app/bookmarks/last-success.json` 包含每个平台的源路径、读取时间、有序条目和重复数。临时文件写入、sync、原子替换，权限 0600。
- 写副本失败不发布新列表，回退同路径的旧副本并警告；无匹配副本则该来源不展示数据。有效源为空时副本也更新为空。
- 停用来源隐藏列表但保留副本。搜索/筛选不自动取消选择；源删除或停用使选中项不可用时回空状态，不自动选第一条。
- 每页 40 条。折叠、筛选、搜索和选择仅保留本轮运行，不承诺退出恢复。

## 人工验收

1. 启用已配置来源，保存后查看列表；首次不自动选择帖子。与 Obsidian 对比顺序。
2. 搜索标题或链接，切换平台，确认无额外排序；选中一条，再过滤掉它，中间仍保持原选中内容。
3. 收起左侧，中间区域扩展，设置入口仍可用；重新展开，搜索/筛选/选择保留。
4. 查看来源状态，确认原始文件/副本/失败/停用区别清楚。
5. 在自己创建的笔记副本上验证删除、空表和非法行，退出重启后核对。不要为验收改坏正式笔记。
6. 修改来源路径时确认旧路径缓存不会当成新路径的数据；来源失败不阻断其他来源。

看到帖子信息并不意味着原页已加载，本轮不进入 A4。
