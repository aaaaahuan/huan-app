# Other 平台接入与验收

验收日期：2026-10-05。本次在现有字幕改动基础上增量接入 Other，不调整字幕服务规则。

## 实现范围

- 第五个平台 `other`：来源配置、图标、筛选、搜索、收藏缓存、原页阅读和独立平台会话。旧配置缺失 Other 时停用、空路径、内存会话，不自动猜测笔记路径。
- 沿用原 Markdown 收藏表格及已读写回机制；通用循环覆盖 Other，空链接行继续跳过。
- Other HTTP(S) 文章使用 Readability，兼容 section/div 长文及最多四个可见、已加载、URL 同源的直接子 frame；不抓取其他标签页或外链。
- 每轮同步冻结页面目录、身份和字幕位置；Other 当前正文刷新纳入 AI run，取消、超时或过期后不会启动后续 frame 或混入新选页面。
- 不增加测试脚本、测试依赖、固定文章地址或内置本机来源路径。README 和 bundled personal-notes 技能已同步。

## 发现与修复

首轮发现父页简介可读，但 iframe 正文未进入快照。根因是结构化正文的短 p / section 排版未通过长段落预检；修复后经 Readability 实际读到章节内数据，并验证标签页切换后的更新。

复审还发现刷新在会话 run 之前等待、超时后可能继续解析其他 frame、页面世界异常消息未限长三个问题，均已修复，复审无新的确认问题。

## 限制

Readability 是启发式，不保证任意网站完整提取、排除全部评论或识别所有敏感内容。子 frame 使用页面世界，不能承诺防篡改或绝无副作用；未改变浏览器安全权限。跨源、嵌套或未显示 frame 不提取。停止及超时的资源边界已静态复核，本次没有人为制造超时、跨源或 renderer 崩溃场景。Other 已读写回沿用既有通用实现，本次为保护真实笔记未做落盘切换验收。
