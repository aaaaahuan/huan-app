# v2.3 视觉重构实施与验收记录

日期：2026-10-08。

## 已实施

- 顶部阅读 / 翻译导航、紧凑在线 / 离线模型菜单与设置入口，移除常驻系统导航列。
- 统一灰绿底、白色内容区与深绿操作色；阅读工具栏横跨整个工作区，与正文及侧栏对齐。
- 左右隐藏宽度为 0，没有折叠轨、边框或残留拖柄。组件保持挂载，保留本轮搜索、筛选、草稿与字幕状态。
- 收藏 / 伴读恢复按钮始终在阅读工具栏；新增专注阅读，记住进入前布局，主动展开单侧时退出专注。
- 基于实际宽度的双侧 / 单侧预算，正文列预留 520px；收起恢复不覆盖宽度偏好。
- 收藏两行标题与轻量日期分组；聊天整合实际模型、工具、来源和写入明细，错误仍直接可见。
- 字幕双列时间 / 正文、跟随状态和恢复入口，保留现有位置、选字和复制规则。
- 翻译双文本区、真实请求模型与独立提交 / 停止规则；设置内部纵向分类、固定头尾和可滚动表单。
- 调宽期间原页保持显示，随布局变化更新矩形，不调用 suspend、取消采集或重新加载网页。

## 不变边界

本轮视觉重构本身不修改主进程、preload、Worker 或通信契约。原页加载与登录态、手动采集 / 去重 / 清空 / 发送冻结、全局临时 main 对话、云端与写入确认、字幕获取、翻译请求版本和设置草稿等原有流程保留。

地址栏仍只读；翻译仍在请求结束后一次性显示返回文本，不新增附件、模型、字幕识别或翻译语言。方案 P1 的清空内联确认和跨原生网页快捷键未实施，清空继续采用现有直接动作。

## 已执行检查

- 使用 Node 24.16.0 执行 pnpm check：Node / Web 类型检查、全仓 ESLint、生产构建通过。
- 三组独立只读交叉审阅：面板与原生矩形、聊天 / 字幕 / 收藏、翻译 / 设置与权限，发现的焦点对比和空态滚动问题已修正。
- 静态宽度推导：940px 窗口扣除左右 16px，默认单侧右栏 320px 与 12px 拖柄后，正文约 576px；实际字体宽度仍需实机验证。
- 本次 renderer 与文档差异格式检查通过。全工作区 git diff --check 在既有主进程 / Worker 修改中报告四处尾部空白，本次没有整理这些无关修改。

构建出现依赖 zod 的 PURE 注释位置警告，不影响构建结果，未改动依赖或锁文件。

## 尚未通过的实机验收

Computer Use 可取得应用清单，但连接当前 Electron 的 bundle ID、完整路径及名称均超时，重置后仍无法取得原生窗口状态。未绕过工具使用其他原生自动化方式，也未将静态审阅等同于 GUI 验收。

因此以下项目仍待真实 Electron 操作确认：

1. 940×640、默认窗口和最大化时工具栏、设置保存、聊天输入与字幕重试的实际可达性。
2. 展开 / 专注 / 翻译 / 设置往返的原生网页裁剪、位置、无穿透与无异常闪白。
3. 跨原生网页边界拖动、失焦结束、隐藏区键盘焦点和设置关闭焦点恢复。
4. 真实视频字幕跟随 / 选字 / 定位及在途聊天、翻译、采集的视觉回归。

视觉实施阶段未请求在线模型、付费字幕、连接测试或笔记写入，未改变用户配置、模型选择或收藏已读状态；未打包发布。

## 提交范围

用户确认提交后，将视觉重构与此前未提交的页面上下文采集功能一起纳入提交。新版阅读界面依赖该功能的主进程、preload、共享通信契约及 read_page 工具说明；这些属于此前的功能实现，不是本轮视觉重构新增的业务变更。local-model.ts、bootstrap.ts 与 workers/ai/index.ts 的仅空白改动保留在工作区，不纳入提交。提交前重新执行 pnpm check 通过；实机验收仍未完成，不推送远端。

## 阅读面板后续调整

- 侧栏拖拽不再主动隐藏原页，保留实时矩形更新、指针捕获和停止拖动收尾。
- 固定应用根节点及面板外壳的滚动边界，仅内容区滚动；标题、搜索和输入区不被 flex 压缩。收藏、消息、字幕及可滚动空态 / 提示区设置 overscroll-behavior，避免滚动向祖先传播。聊天空态改用可增长的消息内布局，不强制 100% 最小高度。
- 普通网页删除伴读区域顶部的单项页签和收起按钮，只保留 URL 右侧开关；YouTube 保留「对话 / 实时字幕」。移除「全局临时对话」文案，不重建聊天或字幕组件，普通聊天改用独立区域名称，避免引用不存在的页签。
- X 预览未发现应用专属水平偏移、样式注入或 UA 修改；原生矩形直接取阅读占位区。默认双侧展开时网页约 580px 宽，可能影响原站响应式布局，但缺少截图及实际 DOM 证据，不能断言左侧留白原因；未擅自裁切原站导航或修改其样式。

用户报告的持续滚动留白尚需截图 / 实机复现区分；应用未开启 Electron scrollBounce，不能将回弹或空态 padding 当作已证实根因。Computer Use 本轮读取应用清单仍超时，未完成真实界面验收。
