# huan-app

独立 macOS 桌面应用，顶部导航切换阅读、翻译和算法训练，右上角打开全局设置，通过紧凑菜单选择在线或离线 AI。工作台统一灰绿底色、白色阅读表面与深绿操作色。基础阅读与 AI 独立；已实现本地收藏、原页容器、分平台会话策略、Readability 页面缓存、Pi SDK 工具式伴读、YouTube 字幕阅读、中英互译，以及 Obsidian 算法清单。聊天和翻译共用模型选择：在线 DeepSeek Flash，离线 Qwen3.5-4B。字幕获取使用官方 REST API，自动检测原语言并在提交前预检费用。

## 开发与验证

开发需要 macOS、Node 24.16.0、pnpm 10.12.1；首次安装需要下载 Electron。最终用户不需要 Node 或 pnpm。

```sh
nvm use
corepack enable
corepack prepare pnpm@10.12.1 --activate
pnpm install --frozen-lockfile
pnpm dev
# 退出开发应用后执行
pnpm check
pnpm pack:arm64
```

产物：`release/mac-arm64/huan-app.app`。Intel 使用 `pnpm pack:x64`，需真机另行验收。当前未签名、未公证，不用于公开发行。图标使用已确认的原设计 `build/icon.png`，由 electron-builder 转换为 macOS 图标资源。

当前不引入自动化测试框架。`pnpm check` 仅执行类型检查、Lint 和生产构建；运行行为需人工 Review 与真实 Electron 界面验证。v2.3 本轮的代码检查及未完成的实机项目见 [视觉重构验收记录](docs/v2.3-visual-review.md)。

`pnpm build` 仅生成 `out/`。`pnpm pack:arm64` 先执行 build，再由 electron-builder 按 `electron-builder.yml` 将编译结果、运行依赖、Electron 和图标打包到 `release/mac-arm64/huan-app.app`。`--dir` 只生成应用包，不生成 DMG/ZIP，也不自动复制到桌面。

生产模式加载 `app://ui/index.html`，不依赖开发服务器或 huan-cli。主进程编译为 `out/main/index.js`，preload 为 `out/preload/index.js`。

收藏列表统一为平台图标、最多两行标题与单行 URL，超出省略并通过原生 tooltip 提供全文。共享控件由 props 驱动，来源卡片、会话卡片和阅读空状态留在对应功能模块；IPC 与业务状态不进入通用组件。

输入聚焦统一由共享控件样式维护：搜索、路径、API Key、只读地址以及模型/平台选择使用绿色细边框和 3px 淡绿光晕，错误输入保留红色边框及光晕，聚焦不改变尺寸。AI 提问框只高亮外层输入表面，不给文字区重复描边；发送按钮与 Key 显隐按钮保留独立键盘焦点。复选框保持键盘轮廓，隐藏的会话单选框只高亮可见选项。翻译页沿用已确认的原样式，包括原文/译文表面和语言选择器。当前 CSS 的浏览器样本校验通过，原生 Electron 窗口验收因 computer-use 超时未完成。

两侧边界默认不显示竖线，悬浮或键盘聚焦时显示调宽拖柄；支持拖拽与左右方向键（Home / End 到最小 / 最大宽度）。收藏栏 240–420px，AI 栏 280–520px，默认 280 / 320px，为中间阅读列预留至少 520px。窗口不足以同时展开双侧时，优先保留最近操作的一侧；缩窗不覆盖宽度偏好。折叠后宽度与分隔条真正归零，展开恢复本轮偏好，不写入设置。拖拽期间原生网页保持可见，并随布局变化更新矩形，不调用 suspend、取消采集或重新加载网页。

阅读工具栏横跨工作区，统一收藏、后退/前进、刷新、只读 URL、提取上下文、采集状态、更多与 AI 伴读入口；「更多」在网页矩形之外展开清空材料操作。顶部「收藏 / AI 伴读」始终可恢复对应面板；收藏栏内仍可收起，伴读面板只保留 URL 右侧的开关，不再重复展示单项标题或收起按钮。普通网页直接显示聊天，YouTube 保留「对话 / 实时字幕」切换；去除聊天顶部的「全局临时对话」文案，不改变会话语义。不再有 52px 收起轨。隐藏组件仍挂载，保留收藏筛选、聊天草稿与字幕状态，且隐藏控件退出焦点顺序。「专注」暂时隐藏双侧，再次点击恢复进入前的展开情况；专注期间主动展开一侧则以该次操作为准。未新增全局快捷键、跨重启布局持久化或清空材料确认。

工作台和侧栏外壳不参与滚动，收藏、聊天消息和字幕正文分别在内部滚动；搜索、标题与聊天输入区保留在固定位置。内容滚动区禁止向父级传递越界滚动，短窗口下较长的配置空态或输入区提示仍可在各自区域滚动。未修改原生远程网页自身的滚动规则。

根目录 `tsconfig.json` 作为编辑器的项目入口，引用 Node 与 Web 两套配置。`src/renderer/src/env.d.ts` 统一声明 `window.huanApp`；声明只提供类型，实际对象由 preload 注入。

跨模块导入使用 `@shared/*`、`@main/*`、`@renderer/*`；同目录导入保留相对路径。别名同时在 TypeScript 与 electron-vite 中配置，不能用来替代 `join()` 中的文件系统路径。IPC 通道统一定义在 `src/shared/ipc-channels.ts`，通过 `IPC_CHANNELS.browser.select` 等常量引用；参数类型保留在 contracts，来源校验与处理函数保留在对应功能模块。

## 数据与 Review

正常启动使用 `~/.huan-app/`。配置保存至 `~/.huan-app/settings.json`，支持 X、Reddit、YouTube、微信文章和 Other 五个来源，首次无配置时均停用；旧配置缺少微信或 Other 时默认停用、使用内存会话。Other 用于其他网站链接，沿用相同收藏表格，在设置中选择并启用对应 Markdown 文件，不猜测本机路径。启动读取启用来源，保存设置仅重读变更来源；关窗再打开不重读，不定时扫描。选中收藏后加载远程网页并按支持范围在本机提取正文，不自动发起 AI 请求或标记已读。

最近成功的解析结果保存在 `~/.huan-app/bookmarks/last-success.json`。解析保留原文件行顺序，跨文件按 X、Reddit、YouTube、微信、Other 拼接，以平台 + URL 去重保留第一次。列表在搜索和平台筛选后按采集日期（YYYY-MM-DD）倒序展示，按天显示低干扰日期组标题；同日保留原顺序，缺失或无效日期统一归入末尾“日期未知”。采集日期不代表平台实际收藏时间，排序不改动原笔记。空链接、格式无效或非安全 HTTP(S) 链接的记录直接跳过，不影响其他收藏读取，也不删除原记录；表格结构错误仍会报错。成功读取反映源端删除；有效空表清空对应来源。失败仅使用同一路径的有效副本，并明确提示，来源路径变更后不会挪用旧路径的数据。停用来源不展示，但不删除其已有副本。

收藏表格在原有“采集日期”“标题 / 列表文字”“来源”“帖子链接”四列后增加“是否已读”，填写“是 / 否”；旧四列表格及空值视为未读，也接受“已读 / 未读”。卡片右侧勾选框手动切换：勾选为已读，取消为未读，打开帖子不会自动标记。仅该操作写回原笔记；首次修改旧表格时补列，保留其他单元格、表外内容和换行。重复 URL 的记录一起更新。写入前重读并做乐观冲突检查，同目录临时文件原子替换；这不是跨应用文件锁，仍应避免与 Obsidian 同时编辑。使用缓存副本时禁止修改；原文件成功而副本更新失败会单独提示，不回退已提交状态。

列表支持标题/链接搜索、平台筛选、全量滚动展示、折叠和选择，不再分页。搜索与平台筛选位于同一行，空列表显示轻量书签图标与简短状态说明，底部不显示来源状态；读取异常仍在应用顶部提示。这些界面状态保留在本轮运行中，退出后重置。搜索与折叠不改变选中项，刷新后条目不再存在则回空状态，不自动选中其他帖子。选中收藏通过 WebContentsView 加载原页，支持前进/后退、刷新/停止；切换其他收藏后返回会重新加载原始 URL。页面内跳转不会改变选中收藏。

Review：打开右上角设置，为平台选择符合收藏表格格式（兼容旧四列）的 Markdown 文件并启用；保存后点击收藏阅读原页。原页无应用 preload，不可调用文件或设置接口。下载、非 HTTP/HTTPS 主页面导航、权限请求和 POST 弹窗暂不支持，不保证各平台第三方登录流程兼容。当前记录见 [A5/A6 验收](docs/a5-a6-review.md)，历史清单见 [A4](docs/a4-review.md)、[A2/A3](docs/a2-a3-review.md) 与 [A1](docs/a1-review.md)。

## 模型选择

顶部以一个模型菜单提供「在线 · DeepSeek Flash / 离线 · Qwen3.5-4B」，不增加模型或供应商。默认在线，选择通过既有设置原子保存，重启后保留；旧配置缺少 `model` 字段时沿用默认值，不改变凭据或收藏配置。离线聊天和翻译不需要 DeepSeek Key，没有静默云端回退。

伴读由一个 reading AgentHandle 管理当前 Session；翻译和 Key 测试各使用独立的 isolated AgentHandle，每次执行创建独立 Session。主进程每次提交读取并冻结 Provider、模型及凭据；切换只影响下一次提交，不中断在途生成、不清历史或草稿。保存选择期间暂不能发起新请求，仍可停止在途请求。每轮聊天显示实际模型。离线历史首次继续交给在线模型时需原生确认，可取消或新开对话避免发送旧内容。

这里的“离线”只控制 AI 推理，不是全应用断网开关：原页浏览、视频字幕获取及字幕用量查询保持原有网络行为。本地已有正文、字幕和已授权笔记可用于离线问答，不能离线获取尚未缓存的网络内容。

Provider 适配在 `src/main/ai/core/providers.ts`，候选模型在 `src/shared/contracts/models.ts`。主进程的 AIService 通过 PiAdapter 装配 Pi AgentHarness；在线 DeepSeek 与本地 Qwen 均使用 Pi AI 的 OpenAI Chat Completions 适配器。聊天和翻译共用一个驻留 llama-server，本地服务的单 slot 串行处理请求。未来增加同供应商模型需更新候选列表；增加供应商还需明确接入凭据、端点和 Provider。

## 算法训练

顶部“算法训练”读取当前用户 `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/huan-space/raw/leetcode-raw.md`，不依赖 AI 笔记工具授权，不联网抓题、不复制题面或自动检测 LeetCode 提交。首批清单由人工核验的 8 个分类、每类 5 道中等题组成；分类不是应用内置枚举，后续修改、增删、排序均直接在 Obsidian 维护。应用提供刷新笔记、未完成筛选、原链接、完成勾选和每题心得，没有编辑清单源文件、分类总结或下一题按钮。

表格必须包含以下四列，可调整列顺序。分类按首次出现顺序，题目按源文件行顺序显示；完成进度按完整分类计算，不受筛选影响。题目标题与帖子链接均在系统默认浏览器打开原链接，支持普通 URL、尖括号 URL 和 Markdown 链接，仅接受不携带用户名/密码的 HTTP(S)。页面切换保留本轮分类及筛选，不重建阅读区。

```md
| 分类 | 题目 | 帖子链接 | 是否已完成 |
| --- | --- | --- | --- |
| 数组与哈希 | 49. 字母异位词分组 | https://leetcode.com/problems/group-anagrams/ | 否 |
```

“是否已完成”只接受“是 / 否”，勾选只改该题单元格，保留其他内容、链接、BOM、换行和顺序。身份由分类及原 URL 决定；同分类重复链接只展示第一次，完成状态必须一致，勾选同步修改所有重复行；不同分类的同链接独立管理。代码块内的示例表格不读取。缺表格、坏链接、缺列或非法状态会明确报错；合法空表清空列表。读取失败保留本轮最近有效清单，但禁用链接和勾选，刷新成功后恢复。

首次进入读取笔记，修改 Obsidian 后点击“刷新笔记”。读取限普通 UTF-8 文件、8 MB、10 秒；不读写符号链接、不创建备用数据库。写入前重读、核对该题期望完成状态，再做文件元信息和全文冲突检查，以同目录临时文件同步后原子替换。失败不先勾选，不自动重试。该机制不是跨应用锁；不要在勾选写入期间同时编辑同一文件。本地保存不等于 iCloud 同步完成。验收记录见 [算法清单验收](docs/algorithms-review.md)。

### 解题心得与 Obsidian

每题的“写心得 / 查看心得”打开 Markdown 编辑详情，支持安全预览、保存按钮、`Cmd+S` 和 Obsidian 跳转。首次打开只显示模板，首次保存才在上述笔记库的 `project/algorithm-training/<分类>/0049-字母异位词分组.md` 等路径建文件，不批量创建空心得。心得与 Obsidian 共用文件，不另建正文数据库，不自动发给 AI。清单仍是分类、顺序与完成状态的来源，心得不重复存完成状态。

YAML 的 `problem_key` 是稳定关联标识，请勿删除或修改；LeetCode 中英文站同一 slug 共用一篇心得，其他链接按去掉片段后的完整 URL 摘要关联。改标题、改分类不会自动改名或搬动已有文件；在心得目录内自行改名或移动后可重新定位，重复 `problem_key` 明确报错。使用 UTF-8 普通 `.md`，保持目录与符号链接校验；文件大小、YAML 大小、目录深度、条目数和累计大小交由实际读取处理，自定义 YAML 属性及正文在保存时原样保留。

目录监听、窗口聚焦、重新进入算法页和手动刷新都会重新核对心得。没有草稿时载入外部修改；已有草稿时保留内容，提示对比、另存草稿副本或手动合并后保存。副本保存到 `冲突副本/`，不参与正式心得索引。外部删除 / 移出目录不会被旧草稿自动重建。切题、切分类及退出时保护未保存草稿；切换阅读 / 翻译保留本轮草稿，但未保存草稿没有崩溃恢复持久化。

更新使用内容摘要和文件快照检查后原子替换；新建使用不覆盖提交。同名未关联文件、重复身份、无效 YAML、权限或下载失败均不以旧内容覆盖。此机制不是跨应用锁，仍可能存在另一进程在最终检查和替换之间写入的竞态；监听也不保证所有文件系统事件到达，保存前重读作为兜底。只确认本地保存，不确认 iCloud 同步。预览不执行 HTML、不加载外部图片，双链、图片和 Obsidian 扩展语法保留原文、在 Obsidian 查看。验收记录见 [心得验收](docs/algorithm-notes-review.md)。

## 翻译

翻译页手动选择英语→中文或中文→英语，点击翻译或按 `Cmd+Enter` 提交，普通 Enter 换行。按顶部模型选择通过独立的 translate AgentHandle 执行一次请求，界面只显示最终译文，主进程汇总底层流。在线模式会将原文发送给 DeepSeek，可能产生费用。交换语言时仅将完整译文回填到原文；支持清空、复制和停止。切离翻译页停止当前请求，返回保留本轮草稿；阅读组件和原生网页保留，聊天草稿、选中收藏及栏宽保持。翻译草稿和结果不写入界面持久化存储，底层执行记录按 Run 留存。

原文与译文区域随窗口剩余空间展开。翻译期间原文仍可聚焦、选取和编辑，语言切换与新提交继续保持单请求约束；修改原文后丢弃该请求的迟到译文，并提示重新翻译，即使又改回相同文字也不接纳旧结果。编辑不会自动取消或重新提交，需点击停止或等待当前请求结束。

直接引用既有 Qwen3.5-4B Q4_K_M GGUF 和 llama.cpp b11429 `llama-server`。在“设置 → AI 伴读 → 离线模型”填写权重文件和程序的绝对路径，保存到本机 `~/.huan-app/settings.json`，开发版和 Finder 启动的打包版共用配置。仅选择可信的 llama-server，保存新的程序路径时需原生确认其执行权限；保留程序目录中的配套动态库。路径优先级为环境变量、已保存设置、开发默认位置；未配置时开发态依次检查 `../model`、`../../model`，兼容工程移入 `huan/` 分组目录。

应用界面加载完成后在后台启动并加载模型，后续驻留，不等待首次翻译才启动。预热不阻塞界面；尚未就绪时提交翻译会等待同一次启动，不创建重复进程。后台启动失败通过翻译页显示具体错误；保存正确路径后，下次手动请求重新启动。已驻留模型更换路径后，通过 `Cmd+Q` 完全退出并重启以加载新配置。关窗只隐藏，`Cmd+Q` 清理本应用启动的模型进程。模型内存占用提前到应用启动后，即使未使用翻译也会驻留。终端启动也可通过环境变量覆盖已保存路径：

```sh
HUAN_MODEL_PATH=/Users/bytedance/Desktop/llm/model/models/Qwen3.5-4B-Q4_K_M.gguf \
HUAN_LLAMA_SERVER_PATH=/Users/bytedance/Desktop/llm/model/runtime/llama/llama-b11429/llama-server \
pnpm dev
```

权重和 runtime 均保留在工程与安装包之外。打包态使用已保存路径或环境变量；首次使用时先在设置中完成路径配置，之后 Finder 启动可直接读取。

本地服务仅监听 `127.0.0.1` 随机端口，使用每次启动的新认证令牌，服务端口和认证令牌保留在主进程。权重与程序路径仅通过既有可信设置接口编辑。不开 Web UI、不下载模型、不继承其他 llama 参数或云端 Key。不主动输出原文/译文日志，原生诊断只在内存中保存并在失败时显示。

不设置翻译输入字符上限；空白内容不提交。本地推理保持引擎默认上下文适配，输出 `n_predict=-1`，禁用上下文静默滑移；`node:http` 流式 transport 只受调用者取消控制，不继承 fetch 响应头超时或云端 SDK 等待预算，也不新增本地输出上限。HTTP/模型错误显示；引擎若因上下文容量结束生成，会明确标记译文不完整，而非伪装成功。在线请求仍受 SDK 默认网络预算和服务商上下文、输出限制约束。超长输入可能报错、耗时很久或耗尽资源；取消不保证释放驻留模型内存。首次模型启动另有 60 秒健康检查保护。

此前开发态实机记录与未验证边界见 [翻译验收](docs/translation-review.md)，统一 Provider 后的验收见 [Provider 验收](docs/provider-review.md)。尚未接入实时字幕翻译。

## AI 伴读

在线模式当前使用 DeepSeek Flash（`deepseek-flash`），固定官方 Chat Completions 端点；离线使用既有 Qwen3.5-4B 权重，复用同一 Agent、工具、流式输出和停止机制。在线 Key 在“AI 伴读”设置中输入后点击“保存设置”；不会读取 Pi CLI 认证、环境 Key 或用户扩展。Key 用 Electron safeStorage 加密保存为 `~/.huan-app/key-<UUID>.bin`，设置只保存引用。替换/清除 Key 不清空聊天，在途请求保留自身认证。未签名构建的 Keychain 行为需实机验证。

与字幕服务相同，DeepSeek Key 默认只展示掩码；点击眼睛才通过可信 IPC 读取当前保存值，隐藏、切换设置 tab 或关闭面板后清除展示明文。显隐不修改配置，不触发连接测试；留空保持保存值不变，清除仍需点击“清除 Key”并保存设置。

页面提取与 AI 独立：`page-host.ts` 监听完整导航和站内切页，加载后等待 1.5 秒让动态内容渲染，再用 `readability.ts` 在隔离世界对 DOM 副本直接调用 Readability。所有平台的 HTTP(S) 页面均可尝试提取，使用提取结果而非结构、路由或密码框预筛决定是否有正文。自动提取执行一次，空结果或异常在阅读区显示，可通过顶部按钮再次采集。页面加载和提取由实际结果或用户停止结束。中间视图关闭后台节流。视频问题仍使用字幕工具，网页文字不当作视频内容。提取仅在本机进行，提问并获得材料授权后 AI 才能读取冻结快照。Readability 仍是启发式正文识别，发送前应核对材料。

AI 来源 URL 移除片段，并按参数名净化查询字段；Other 仅保留常见文章定位参数 `id`、`p`、`page_id`、`post_id`、`article_id`、`story_id` 和 `lang`，值限 128 个 ASCII 字母、数字、下划线或连字符，不保留常见跟踪及授权字段。这不是敏感信息检测器，不能保证允许字段及路径中不含隐私信息。Other 的片段导航按实际地址区分快照，避免 hash 路由切换文章后沿用旧正文；但非常见查询参数或 hash 定位的站点，其净化后的来源链接可能不完整，应结合标题核对。原页和收藏 URL 不变。

页面提取兼容已加载且显示的同源嵌入正文：主隔离世界采集 iframe 地址，读取与父页同源、可见 src 与 native 直接子 frame 唯一匹配的正文。Electron 子 frame API 不提供隔离世界执行接口，子 frame 使用固定页面世界闭包提取 DOM 副本，仍核对格式与 frame 身份，保持 sandbox / Node / preload 权限。子页面执行异常直接显示；未识别到正文的子页面跳过。提问统一冻结已保存的累计快照，当前 DOM 更新通过自动采集和手动按钮进入材料，避免提问时再次提取失败让已有正文失效。取消和导航后的迟到结果丢弃；已发出的 renderer JavaScript 无法强制中断。

`page-store.ts` 在主进程保存页面快照，不再按页数淘汰或按标题、正文长度截断。本次运行中同一个完整实际 URL 复用一个页面 ID，查询或片段不同的 URL 不因来源链接净化而合并；内部地址索引不传给 AI。异步结果仍需匹配容器、页面身份和导航才能入库。状态区分加载中、已提取、不可用和不支持；页面关闭清当前指针，退出清内存。不向日志输出提取的正文。缓存及每轮冻结快照会随材料累积占用更多内存，没有应用级容量兜底。

阅读区顶部新增“页面上下文提取”：保留首次自动采集；用户切换同 URL 的 Tab 或展开内容后，等待正文显示完成再点击，将当前提取结果追加到同一页面快照。每段带采集序号及时间，最新采集排在最后，不把所有段当作同时可见的页面；完全相同正文不重复保存，重新采集已有正文会更新其时间和最新位置。次数按去重后的采集段统计，首次自动采集也计入。界面显示次数与最后采集时间；提取失败保留已有成功材料，导航、关闭或切换设置后丢弃迟到结果。未新增 Tab 自动识别或持续 DOM 监听，Readability 仍不能保证排除全部隐藏面板。网页视窗使用与工具栏对齐的内缩圆角边框，原生网页视图也设置对应圆角。

“清空本页上下文”只删除该 URL 的本机采集材料，保持空白直到再次手动采集；不删除收藏、登录态、字幕或聊天历史。已经进入 Agent 历史的材料不能通过清缓存撤回，需要新开对话清除历史。提问时复制累计文本，之后采集或清空只影响下一轮，不修改已发送的快照。`read_page` 默认返回全文，已有 `offset` 参数仍可读取指定位置之后的内容，`nextOffset` 为 null。

聊天固定为独立会话，切换收藏或模型不重建组件或 AgentHandle。每次发送时冻结页面快照；在线经版本 2 授权后交给主进程的 reading Agent，旧版仅当前页的授权不能代替新授权；离线处理不需要云端材料授权。模型先收到页面目录，按需调用只读工具 `read_page` 获取正文片段；该工具只能读本轮快照，不访问文件、浏览器或网络。UI 显示工具实际读取的页面来源。无页面、读取失败或拒绝授权仍可正常聊天，模型不得猜测当前帖子；快照更新在下一次发送时生效。

在线视频材料需要版本 3 授权，包含当前视频元信息、已有字幕和冻结播放位置；授权版本只升不降。离线只使用本机已有材料。拒绝新增授权时保留已获授权的文章材料，普通聊天继续。字幕尚不可用时不会伪造正文，播放器位置未知时不附带秒数。

内置技能放在 `skills/<name>/SKILL.md`，由 `src/main/ai/agent/reading-tools.ts` 显式注册名称、描述和源码导入，通过 Vite `?raw` 随主进程打包，开发和生产使用同一份内容。模型先看到技能目录，再用 `read_skill({ name })` 按需加载全文；新增或修改技能需重新构建并重启应用。当前 `personal-notes` 基于本机个人笔记技能，已适配微信和阅读状态列；技能说明只提供操作规范，实际文件读写由显式注册的笔记工具及原生确认控制。工具循环由实际任务结果结束。

Pi Agent Core / Pi AI / Pi Coding Agent 固定为 0.87.1，运行于主进程；模型计算由在线服务或独立的 llama-server 执行。AIService 为伴读、翻译和 Key 测试注册独立 AgentHandle，同一 handle 同时执行一轮；PiAdapter 为每轮装配 Harness、原生工具和 Hook，并以 Pi JSONL Session 保存执行历史。每次模型请求、工具调用与结果、审批决定和最终状态还会写入 `~/.huan-app/ai/runs` 的 Run 事件日志及摘要；应用重启后聊天界面从空 Session 开始，已有执行记录继续保留。伴读输入和材料工具使用完整文本，在线输出采用模型默认预算，本地聊天沿用引擎输出设置；模型的上下文与输出容量仍可能导致真实错误或截断，界面保留错误原因。SDK 网络请求不自动重试。

伴读每条回答下方、翻译结果底部展示本轮 tokens 与请求耗时，展开可查看输入、输出、缓存、推理拆分和模型请求次数。一轮工具循环内的所有模型用量累计，耗时包含模型准备 / 加载、材料准备、工具和确认等待。停止或失败时保留已报告用量，明确标识部分 / 未知；准备阶段失败也展示耗时。指标作为 `metrics` 写入 `run.settled` 与 Run summary，旧记录兼容读取。统计口径、数据结构与验证见 [AI 可观测性](docs/ai-observability.md)。

停止和新开对话沿用 Run 生命周期及实例隔离。停止等待 Pi 原生操作及工具收尾，历史 Hook 在后续请求中选取已结算的对话和真实写入回执。已提交的文件写入保留真实回执，新开对话保留页面缓存和 API Key。消息以纯文本展示。退出后聊天界面从空会话开始，Pi Session 与 Run 记录保存在本机供核对。连接测试使用独立 Session，可能计费，不发送页面内容。

静态检查或成功打包不代表真实网站正文提取、付费模型问答和停止已验收通过。

## YouTube 实时字幕

按 v2.2 技术方案 5.1 实现，仅支持当前浏览器实际 URL 为 HTTPS YouTube `/watch?v=<videoId>` 的页面，不以左侧收藏选择推断视频。右栏保留默认 AI 伴读，新增“实时字幕”Tab；两页持续挂载，切换不清空聊天草稿或重建 Agent。

设置新增“字幕服务”：Transcript Guru Key 经主进程确认视频 URL 发送及费用说明后，用 safeStorage 加密保存；默认只展示保存状态和掩码，点击眼睛按钮时通过可信 IPC 读取当前字幕 Key，隐藏、离开字幕设置或关闭面板后清除展示明文，不改动保存值。配置默认增加 `subtitles: { credentialId: null, consentVersion: 0 }`，兼容旧 settings v1。未保存或正在编辑 Key 时隐藏用量；调用官方余额及消耗接口，首次加载及刷新都有 loading 提示，显示可用/预留 credits、每月发放和近 30 日消耗。credits 不等于 API 调用次数，不伪造未公开的日/月调用配额，提供固定官方后台入口。

按用户后续确认移除新任务的总门禁，不接入 MCP。先调用免费 `POST /api/v1/jobs/estimate`，请求原语言自动检测（`language: auto`、`force_asr: false`）；只在 `db_hit` 或 `caption_youtube`、预估 0 credits、无需确认且足额时提交 `POST /api/v1/jobs`（`language: auto`）。收费、翻译和 ASR 路径不自动提交；已受理任务仅用 GET 续查同一 job，不重复创建。正文仅接受 `source=caption` 或 `extension_upload`（官方浏览器扩展提取后上传的 YouTube 字幕），保留服务实际来源，界面区分浏览器提取；拒绝翻译、ASR 和未知来源，不能以 db_hit 或 0 credits 单独证明原字幕。预估不是服务端费用锁定，实际计费仍以官方记录为准；不承诺通用 API 不会回退，不下载音视频。

主进程按视频管理内存字幕，同视频合并在途 Promise，缓存随本次运行累积；迟到结果校验条目、控制器及凭据，切页不取消其他视频已发出的获取。保留可续查 job 和提交未知记录，只有确定未受理的提交才清除未知标记。更换 Key 会 abort 并等待旧请求收尾，不清聊天和成功正文；重新创建旧账户/未知任务需要确认。字幕正文和任务不写盘，完全退出或清除 YouTube 会话后清空。

已配置并授权字幕 Key 时，检测到当前 YouTube 视频正文开始播放即后台获取字幕，不必先切到“实时字幕”Tab；暂停、广告及不可用的播放器不触发预取。进入字幕 Tab 仍可主动获取，并复用后台在途请求或已完成缓存。后台失败保留现有错误，等待手动重试，不随播放采样循环请求或弹出重新创建任务的确认框；缺 Key 或未授权时不自动联网，播放中保存有效配置后可开始预取。免费费用预检和来源校验保持不变，后台获取仍可能消耗服务 API 调用配额。

播放器在固定隔离世界采样，完成后 250ms 再读，新鲜度 1s、watchdog 2s；导航及广告不沿用旧位置。有效字幕按最远播放位置渐进展开，回退不收回正文；采样不可用时全文手动阅读，恢复后保留已展开文本。手动回看或选文停止跟随，可显式恢复；时间戳定位仅修改当前视频时间，保持播放/暂停状态。复制按选区提取字幕原文，排除时间戳和控件。

每次 AI 发送同步冻结已有全文及位置，`read_subtitles` 默认返回全文，保留 `offset` 兼容，`nextOffset` 为 null。来源详情只在真实读取工具后显示，模型不得将字幕等同于已观测视频画面。Run 结束释放本轮格式化正文。

字幕 provider 按实际响应读取，保留来源、格式、视频身份及时间顺序校验。请求由用户取消或实际服务响应结束，只遵守服务端真实 429 / Retry-After；待处理任务每 2 秒续查同一 job，HTTP 失败交由用户手动重试。HTTP 状态、上游错误和网络原因在现有界面展示，已知 Key 脱敏。超长响应与持续积累的缓存会增加内存占用。

实现和当前实机验收边界见 [5.1 Review](docs/subtitles-review.md)，不以静态检查或模拟结果代替真实字幕成功链路。

## AI 网页搜索与抓取

在线伴读按回合向 Pi AgentHarness 注册 `web_search` 和 `web_fetch`，复用本轮在线模型的 DeepSeek API Key。设置好在线模型后可直接提问“搜索 DeepSeek 最新公告并给出来源”或“读取这个公开网页并总结：https://example.com”。工具名单、调用及结果沿用现有对话和 Run 记录，抓取成功的页面显示来源。离线伴读、翻译和 Key 测试保持原有工具范围。

`web_search` 使用 `POST https://api.deepseek.com/v1/tools/search`，默认返回 5 条（可指定 1–50 条），支持可选正文和原始问题；搜索词及原始问题遵循服务端 128 Unicode 字符限制。`web_fetch` 使用同域 `/v1/tools/fetch`，读取单个 HTTP(S) URL 的 Markdown 正文，不携带本机浏览器 Cookie。当前文章与字幕仍优先读取已授权的本地快照。凭据仅保留在主进程闭包，不进入模型上下文和工具记录。

调用会向 DeepSeek 发送搜索词或 URL，可能计费；[官方计费与限制](https://api-docs.deepseek.com/zh-cn/guides/search/)目前分别为每千次成功搜索/抓取 5 元。停止任务会取消在途 HTTP 请求，但不保证撤销服务商已受理的调用或费用。失败展示 HTTP 状态和可操作提示，不自动重试。网页与搜索结果属于不可信资料；仅提交公开检索所需信息。

## 登录与隐私

设置中的“登录与隐私”按平台提供“仅本次运行 / 重启后保留”。旧配置自动兼容为内存模式，不自动保存登录态。模式在本轮启动时固定，保存更改后需 Cmd+Q 完全退出重启（关窗不算）；不迁移两种模式间的 Cookie。切换至内存模式不会删除此前的持久会话，需要使用“清除会话”单独移除。
